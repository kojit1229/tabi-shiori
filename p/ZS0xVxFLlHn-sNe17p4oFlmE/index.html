🌅 Mauna Lani Beach と メインディナーの日

旅のハイライト
  1. 午前
    🏖️Mauna Lani Beach
    • 砂遊び
    • 浅瀬で水遊び
    • ウミガメ探し

    この日の動き方: 午前ビーチ→宿で休憩→夜ディナーだと、宿とマウナラニを2往復(タクシー4回)することになる。おすすめは、この日だけレンタカー(本館ロビーのNational窓口)か、ビーチのあと Mauna Lani Auberge のロビーやカフェで涼んでそのままディナーへ(帰りの1回だけタクシー)。

    ウミガメがいなくても、とても穏やかなビーチなので小さい子でも十分楽しめる。

    移動: ホテルから北へ車で約15分(マウナラニ・リゾート内)。タクシーか配車アプリで「Mauna Lani Auberge(旧Mauna Lani Bay Hotel)」まで。夜のCanoeHouseも同じ場所なので、フロントで往復を頼むと迷わない。
    ビーチへの道: 一般向けの駐車場は「Kalahuipua'a Historic Park」で、そこから海沿いの小道を徒歩15分。台数が少ないので車なら早めに。子連れ・ベビーカーは、ホテル前で降りてビーチへ向かう方が楽。

    ビーチ案内駐車・アクセスの口コミ地図
  2. 午後
    😴ホテルで少し休憩

    夜に備えて体力を残しておく。

  3. 17:30
    🌅CanoeHouse予約済み 17:30

    旅行のメインディナー。ビーチで遊んだあとの夕暮れ時、海を眺めながら食事。「ハワイ島らしい一日」の締めくくり。

    場所: Mauna Lani Auberge の海沿い(住所 68-1400 Mauna Lani Dr)。営業 17:00〜21:00。服装は「リゾートカジュアル」(襟付きシャツやワンピース程度。ビーチサンダル・水着は避ける)。子ども歓迎。電話 (808) 796-3990。
    帰り: 夜はこの辺りで配車アプリがつかまりにくい。予約時か到着時に帰りのタクシーを店に頼んでおく。

🏡 宿: キングスランド(Kings' Land by Hilton Grand Vacations)

本館から東へ約1.5マイル(2.4km)、ゴルフ場に囲まれたコンドミニアム型のリゾート。部屋にキッチン・洗濯機があり、家族連れ向き。

ここでできること

  • 溶岩岩のプール(スライダー4本)・子ども用プール・大人用プール・ジャグジー
  • Kings' Land Bistro & Lounge(8:00〜19:00)。朝のパン・サンドイッチ・ピザ・子ども用メニュー
  • ゲームルーム(ビリヤード・卓球・ゲーム機)、キッズアクティビティ、ジム
  • 本館のラグーン・プール・ドルフィンクエスト・スパも宿泊者として使える

無料シャトル

  • キングスランド ⇄ 本館 ⇄ Kings' Shops / Queens' MarketPlace を巡回
  • 初日にフロントで時刻表をもらい、最終便の時刻を控える(夜遅い外食のあとはタクシー)
  • 本館へ行くときは水着・タオル・日焼け止めを持って出る(戻るのに往復20分かかる)

キッチンの使い方

  • 買い出しは Queens' MarketPlace の Island Gourmet Markets(食料品・惣菜・お酒。少し高いが便利)
  • 初日に朝食用の牛乳・フルーツ・パン・水を買っておくと、9/20・9/23の朝がゆっくりできる。初日は無料シャトルで Queens' に寄ってから宿へ戻ると1回で済む
  • 9/23の夜はテイクアウトを部屋で。A-Bay's のネット注文が使える

🚌 宿の無料シャトル 時刻表

公式の「Kings' Land Shuttle Schedule」を日本語にしたもの。1周30分の巡回で、コハラスイーツ → ベイクラブ → 本館(下のロビー) → Kings' Shops → Queens' MarketPlace → キングスランド の順に止まります。

読み方

  • 宿 → 本館: 「キングスランド着」の時刻にそのまま乗る(その便が次の周に入る)。本館まで15分
  • 本館 → 宿: 「本館 下のロビー」の時刻に乗る。Kings' Shops(5分)・Queens'(10分)を経て15分で宿
  • ショップ → 宿: Kings' Shops か Queens' の列の時刻に乗る。5〜10分で宿
  • 午前は30分おき、14:30からは15分おき。最終は本館 21:55 発 → 宿 22:10 着
  • 時間どおりに出発し、遅れた人を待たない。5分前には停留所に
  • ルアウの夜(金・日・火)は 16:15〜17:15 と 20:00〜21:00 に本館直行の臨時便あり

旅程に当てはめると

  • 9/20 ドルフィンクエスト 16:00 → 宿 14:55 発か 15:10 発で本館 15:10/15:25 着。ロビーから徒歩15〜20分
  • 9/20 朝食(Queens' 7:00〜) → 宿 7:25 発 → Queens' 7:50 着。帰りは 8:20 か 8:50 に Queens' 発
  • 9/23 A-Bay 夕方のカメ探し → 帰りは Kings' Shops 発 17:15 / 17:30 / 17:45… 15分おき
  • 夜の外食のあとは 22:10 が最終。CanoeHouse・Pueo's からはタクシーで宿へ直接

🔄 予定が変わったときの早見表

「雨が降った」「子どもが疲れた」「カメに会えなかった」など、その場で切り替えるための候補。距離は宿(キングスランド)からの車の時間。

☔ 雨・風が強い本館のKonaプールは屋根なし。→ キングスランドのゲームルーム / Queens' MarketPlace で買い物 / コナの Target・Kona Commons / Ocean Rider タツノオトシゴ農場(空港近く・屋内寄り・要予約)
😴 子どもが疲れた・昼寝が長い→ 予定を丸ごと「宿のプール+Bistro」に置き換える。夜だけ本館へ(シャトル15分おき)
🐢 カメに会えなかった→ 9/23夕方のA-Bayで再挑戦(しおり本文)。それでも会えなければ、コナの Kahaluʻu Beach Park(浅くて確率が高い)
🚗 レンタカーを借りた日→ 北へ20分の Hapuna Beach(島一番の白砂・監視員あり)、または Waialea(69)Beach(木陰が多く子連れ向き)
🍽️ 予約の店に行けなくなった→ 本館なら Nui Italian / Lagoon Grill。A-Bay 沿いなら Lava Lava Beach Club(砂の上で夕食・生演奏・子連れ歓迎)
🌅 夕日を見たい→ 本館 Buddha Point(オーシャンタワー側)/ A-Bay のヤシ並木 / Lava Lava Beach Club のテラス
🚶 歩いて行ける寄り道→ Waikoloa Petroglyph Preserve(Kings' Shops から徒歩10分・古代の岩絵・朝夕がよい)
🛒 買い出しをまとめたい→ ワイコロア・ビレッジの KTA Super Stores(地元スーパー・Pueo's の近く・食料品もお土産も安い)

🎁 定番のお土産と買う場所

何を買うか

  • コナコーヒー: 「100% Kona」表記のものを。「Kona Blend」は1割しか入っていない
  • マカダミアナッツ(Mauna Loa / Hawaiian Host のチョコ): 配りもの向き。スーパーが安い
  • ホノルルクッキー / Big Island Candies: 箱入りで見栄えがよい
  • リリコイ(パッションフルーツ)バター・ハワイ産はちみつ(Big Island Bees)・ハワイアンソルト: 軽くて割れない
  • コナビール(Kona Brewing): 空港や町で。重いので最後に
  • 子ども向け: ウミガメ・イルカのぬいぐるみ(Dolphin Quest の売店)、アロハシャツ、ハワイ限定のお菓子

どこで買うか

  • Island Gourmet Markets(Queens'・徒歩圏): まとめ買いの本命。コーヒー・ナッツ・お菓子・お酒がそろう
  • KTA Super Stores(ワイコロア・ビレッジ・車15分): 地元スーパー。同じものが一段安い
  • Target / Walmart / Costco(コナ): 大量に買うなら。9/21のコナの日に
  • 本館 Big Island MarketPlace: 買い忘れの穴埋め
  • コナ空港の売店: 最後の駆け込み。品ぞろえは少なめ

⚠️ 困りそうなところ

  • 帰りの足: Pueo's・CanoeHouse・コナからの帰りは、店やフロントに帰りのタクシーを頼む。行きの運転手に名刺をもらって帰りも頼むのが一番確実。
  • 宿と本館が別の敷地: キングスランドから本館へは無料シャトル(車5分)。シャトルの最終便の時刻を初日に確認。夜遅くなるならタクシー。
  • 本館が広い: ロビーからドルフィンクエストまで徒歩15〜20分。トラム(モノレール)とボートは待ち時間込みで同じくらい。予約の30分前には動き出す。
  • Hawaiian Style Cafe はワイメア(車30分以上)。行くなら別の日に車を出す前提。
  • Mauna Lani の一般駐車場は台数が少なく、ビーチまで徒歩15分。タクシーでホテル前まで行く方が楽。
  • 現金: シャトル代・チップ用に1ドル札と5ドル札を多めに。
  • 日差し: 9月のコハラ海岸は晴れが多く暑い。ビーチは午前中、13〜15時は屋内かプール。日の入りは18:15ごろなので、夕方のカメ探し(9/23)は17:00〜18:00がちょうどよい。
  • ルアウの日程: 本館のルアウは金・日・火。行くなら 9/20(日)の Pueo's と入れ替えるか、9/22(火)は CanoeHouse があるので不可。

📌 覚えておくこと

  • 予約が入っているのは ドルフィンクエスト(9/20 16:00) と Canoe House(9/22 17:30) の2つ
  • 時差は19時間。初日は早めに寝て体を合わせる
  • ウミガメは見つけても触らない・近づきすぎない
  • 帰国日は14:10発。11時すぎにはホテルを出る
  • Pueo's と Huggo's は予約しておくと安心(リンクから予約可)
  • ESTA(米国の電子渡航認証)を全員分、出発の72時間前までに申請。パスポートの残存期間も確認
  • チャイルドシート: 配車アプリやタクシーは用意がない。小さい子がいるなら、持ち運べる簡易ブースターを持参するか、予約時に相談(holoholo)
  • 海外旅行保険・クレジットカードの海外利用設定・eSIMかWi-Fiを出発前に
